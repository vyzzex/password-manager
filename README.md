# 🔐 Менеджер паролей (Password Manager)

Консольный менеджер паролей на C# (.NET 8) с шифрованием AES-256.

## Возможности

- **AES-256-CBC** шифрование всех чувствительных данных
- **PBKDF2 + SHA-512** деривация ключа из мастер-пароля (600 000 итераций)
- **Уникальная соль** для каждого хранилища + уникальный **IV** для каждой записи
- **Мгновенная валидация** мастер-пароля через canary-метку (без расшифровки всех записей)
- **Атомарная запись** файла (через временный файл — нет риска порчи данных)
- **Генератор паролей** с гибкой настройкой (длина, спецсимволы, цифры)
- **Поиск** по названию сервиса
- **Маскированный ввод** пароля (символы скрыты / отображаются как `*`)

## Принципы SOLID

| Принцип | Применение |
|---------|-----------|
| **S** — Single Responsibility | Каждый класс отвечает за одну задачу: шифрование, хранение, бизнес-логика, UI |
| **O** — Open/Closed | Новые алгоритмы (ChaCha20, AES-GCM) добавляются реализацией `ICryptoService` без изменения остального кода |
| **L** — Liskov Substitution | Любая реализация интерфейсов взаимозаменяема (JSON → SQLite → облако) |
| **I** — Interface Segregation | Интерфейсы минимальны и сфокусированы |
| **D** — Dependency Inversion | Все зависимости передаются через конструктор; `Program.cs` — единственное место, где знают о конкретных реализациях |

## Безопасность

| Компонент | Детали |
|-----------|--------|
| Алгоритм | AES-256-CBC + PKCS7 padding |
| KDF | PBKDF2-SHA512, 600 000 итераций |
| Соль | 32 байта, `RandomNumberGenerator` |
| IV | 16 байт, новый для каждого поля каждой записи |
| Проверка пароля | Canary-метка (зашифрованная строка-маркер) |
| Хранение ключа | Только в памяти (`byte[]`), никогда не попадает в файл |
| Запись файла | Атомарная: temp → `File.Move(overwrite: true)` |
